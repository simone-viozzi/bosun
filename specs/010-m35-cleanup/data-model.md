# Data Model: Milestone 3.5 - Post-M3 Cleanup & Bug Fixes

**Date**: 2026-01-05
**Status**: Draft

## Overview

This milestone modifies existing data types rather than introducing new ones. Changes focus on:
1. Config schema field rename (`BackupEnabled` → `Enabled`)
2. Execution plan completeness (`start_containers` step)
3. Interface alignment (`JobExecutor`)

## Entity Changes

### 1. VolumeConfig (Config Schema)

**Location**: `internal/config/schema/config_v1.go`

**Before**:
```go
type VolumeConfig struct {
    BackupEnabled bool   `bosun:"key=bosun.volume.backupEnabled,..."`
    MaxSize       int64  `bosun:"key=bosun.volume.maxSize,..."`
}
```

**After**:
```go
type VolumeConfig struct {
    Enabled bool   `bosun:"key=bosun.volume.enabled,..."`
    MaxSize int64  `bosun:"key=bosun.volume.maxSize,..."`
}
```

**Impact**:
- Label key changes: `bosun.volume.backupEnabled` → `bosun.volume.enabled`
- Config JSON output changes: `"BackupEnabled"` → `"Enabled"`
- Tests and docs must be updated

### 2. ExecutionPlan (Domain)

**Location**: `internal/domain/jobs/types.go`

**Before** (missing start step):
```go
type ExecutionPlan struct {
    JobName   string
    Steps     []PlanStep  // Only contains: stop_containers, run_worker
    CreatedAt time.Time
}
```

**After** (complete lifecycle):
```go
type ExecutionPlan struct {
    JobName   string
    Steps     []PlanStep  // Contains: stop_containers, run_worker, start_containers
    CreatedAt time.Time
}
```

**Step Types** (existing constants, now all used):
```go
const (
    StepTypeStopContainers  StepType = "stop_containers"
    StepTypeRunWorker       StepType = "run_worker"
    StepTypeStartContainers StepType = "start_containers"  // Now generated by planner
)
```

### 3. JobExecutor (Port Interface)

**Location**: `internal/ports/executor.go`

**Before** (mismatched):
```go
type JobExecutor interface {
    Execute(ctx context.Context, jobName string, opts ExecuteOptions) (ExecutionResult, error)
    DryRun(ctx context.Context, jobName string) (ExecutionPlan, error)
}
```

**After** (aligned with implementation):
```go
type JobExecutor interface {
    Execute(ctx context.Context, job jobs.Job, opts ExecuteOptions) (ExecutionResult, error)
    DryRun(ctx context.Context, job jobs.Job) (ExecutionPlan, error)
}
```

**Rationale**: Discovery is external to executor (Decision #2)

### 4. Executor (Implementation)

**Location**: `internal/app/executor/executor.go`

**Constructor Change**:
```go
// Before
func New(discoverer ports.JobDiscoverer, planner ports.JobPlanner, ...) *Executor

// After (discoverer removed)
func New(planner ports.JobPlanner, compose ports.ComposeController, worker ports.WorkerRunner) *Executor
```

**Method Change**:
```go
// Before: Hardcoded flow
func (e *Executor) ExecuteJob(ctx context.Context, job jobs.Job, opts ExecuteOptions) (*ExecutionResult, error) {
    plan, _ := e.planner.Plan(ctx, job)
    e.compose.StopStack(...)      // Hardcoded
    e.worker.Run(...)             // Hardcoded
    defer e.compose.StartStack(...) // Hardcoded
}

// After: Plan-driven interpreter
func (e *Executor) Execute(ctx context.Context, job jobs.Job, opts ExecuteOptions) (*ExecutionResult, error) {
    plan, _ := e.planner.Plan(ctx, job)
    for _, step := range plan.Steps {
        result := e.executeStep(ctx, step, opts)
        // Record result per step
    }
}
```

### 5. ValidationErrors (Loader)

**Location**: `internal/config/loader/loader.go`

**New Behavior**:
```go
type ValidationErrors struct {
    Errors   []ValidationError  // Actual errors (scope mismatch, parse failures)
    Warnings []ValidationError  // New: unknown keys (when not strict)
}

// New method
func (e *ValidationErrors) AddUnknownKeyWarning(key string, scope Scope) {
    e.Warnings = append(e.Warnings, ValidationError{
        Key:     key,
        Scope:   scope,
        Message: fmt.Sprintf("unknown key: %s (ignored)", key),
    })
}
```

**New Flag Support**:
```go
type LoadOptions struct {
    Strict bool  // If true, unknown keys are errors; if false (default), warnings
}
```

## Validation Rules

### Label Validation (Lenient Mode)

| Condition | Result | Message |
|-----------|--------|---------|
| Known key, valid value | ✅ Pass | — |
| Known key, invalid value | ❌ Error | `invalid <type> for key '<key>': <error>` |
| Known key, wrong scope | ❌ Error | `key '<key>' not allowed on scope '<scope>'` |
| Unknown `bosun.*` key | ⚠️ Warning | `unknown key: <key> (ignored)` |
| Unknown `bosun.*` key (strict) | ❌ Error | `unknown key: <key>` |

### Execution Plan Validation

| Condition | Result |
|-----------|--------|
| Job has target containers | Plan includes `stop_containers` + `start_containers` |
| Job has no target containers | Plan only includes `run_worker` |
| Plan has steps | Executor iterates all steps |
| Step fails | Record failure, continue to next step (restart always attempted) |

## Migration Notes

### Breaking Changes

1. **Label rename**: `bosun.volume.backupEnabled` → `bosun.volume.enabled`
   - Existing compose files need updating
   - No backward compatibility alias (pre-1.0 decision)

2. **Config output rename**: `"BackupEnabled"` → `"Enabled"`
   - Scripts parsing JSON output need updating

### Test Impact

| Test Category | Expected Changes |
|---------------|------------------|
| Unit tests | Update label keys, field names |
| Integration tests | Update compose files, assertions |
| Golden files | Update expected JSON output |
